# ROiCORE — ระบบติดตามและแจ้งเตือนสถานการณ์น้ำท่วม

แพลตฟอร์มศูนย์กลางสำหรับตรวจสอบเส้นทาง เฝ้าระวังระดับน้ำ และรายงานสถานการณ์น้ำท่วม เพื่อให้ประชาชนและผู้สัญจรวางแผนการเดินทางได้อย่างปลอดภัย พัฒนาด้วยสถาปัตยกรรมเชิงวัตถุเต็มรูปแบบ

---

## สถาปัตยกรรมระบบ

ระบบถูกออกแบบแยกชั้นตามหลักการออกแบบเชิงวัตถุอย่างชัดเจน:

- **Domain Layer:**
  - **Entities:** ข้อมูลรายงานสถานการณ์น้ำท่วม และจุดเฝ้าระวังน้ำท่วม
  - **Enums:** ระดับความรุนแรง สถานะรายงาน และระดับความเสี่ยง
  - **Value Objects:** พิกัดภูมิศาสตร์ ขอบเขตพื้นที่ และข้อมูลสภาพอากาศ
  - **Strategies:** กลยุทธ์การประเมินระดับความเสี่ยงอัตโนมัติตามระดับน้ำและปริมาณฝน
  - **Use Cases:** กรณีการใช้งานส่งรายงาน ตรวจสอบจุดน้ำท่วม และดึงข้อมูลสภาพอากาศ

- **Data Layer:**
  - ที่เก็บข้อมูลรายงานและจุดน้ำท่วม
  - บริการเชื่อมต่อสภาพอากาศและปริมาณฝน

- **Presentation Layer:**
  - ตัวควบคุมเส้นทางการเชื่อมต่อข้อมูล
  - หน้าทดสอบระบบการเชื่อมต่อข้อมูล

## การติดตั้งและเริ่มใช้งาน

### 1. ติดตั้งชุดโปรแกรม
```bash
composer install
```

### 2. ตั้งค่าสภาพแวดล้อม
คัดลอกไฟล์ `.env.example` เป็น `.env`
```bash
cp .env.example .env
```

### 3. รันชุดทดสอบ
```bash
composer test
```

### 4. เปิดใช้งานหน้าทดสอบ
เปิดผ่านเว็บเซิร์ฟเวอร์ เช่น Laragon หรือเซิร์ฟเวอร์จำลอง:
```bash
php -S localhost:8000 -t public
```
เข้าใช้งานผ่านเว็บเบราว์เซอร์ที่ `http://localhost:8000`
