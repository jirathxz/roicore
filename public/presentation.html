สถาปัตยกรรม Clean Architecture & โดเมนโมเดล OOP

แยกแกนกลางทางธุรกิจ (Domain Layer) เป็นอิสระจากฐานข้อมูล

FloodPoint
จุดเฝ้าระวังน้ำท่วม, พิกัด GeoLocation, ระดับน้ำ waterLevel (เมตร) และคำนวณความเสี่ยง
FloodReport
รายงานจากประชาชน, ระดับความรุนแรง, แนบภาพถ่าย, และเบอร์โทรศัพท์
GeoLocation
Encapsulate ละติจูด/ลองจิจูด พร้อม Invariant Validation ตรวจสอบพิกัดในไทย
Domain Enums
RiskLevel (วิกฤต/สูง/ปานกลาง/เฝ้าระวัง), Severity (1-4), และ ReportStatus
1. Encapsulation (การซ่อนข้อมูลภายใน)
GeoLocation และ FloodPoint ซ่อน properties เป็น private มี Validation ภายใน ป้องกันค่าพิกัดผิดพลาด
2. Inheritance (การสืบทอดคุณสมบัติ)
FloodVictim และ Traveler สืบทอดจาก User (Abstract) เพื่อแยกสิทธิ์และฟังก์ชันการทำงาน
3. Polymorphism (พหุสัณฐาน)
IRiskStrategy กำหนด calculate() ให้ CompositeRiskStrategy สลับสูตรคำนวณตามสภาพอากาศได้อิสระ
4. Abstraction (การซ่อนความซับซ้อน)
IFloodPointRepository ซ่อนคำสั่ง SQL และ PostGIS ไว้เบื้องหลัง Domain ไม่ต้องรู้ไส้ในของฐานข้อมูล

3 Design Patterns หลักในการประมวลผลข้อมูล

การประยุกต์ใช้ GoF Patterns เพื่อความยืดหยุ่น การทดสอบ และการคำนวณอัตโนมัติ

Strategy
CompositeRiskStrategy คำนวณคะแนนความเสี่ยงแบบถ่วงน้ำหนัก (น้ำ 40% + ฝน 35% + ความหนาแน่น 25%)
Repository
IFloodPointRepository แยก Data Access ออกจาก Domain พร้อมรองรับ PostGIS ST_DWithin
Adapter
แปลงข้อมูลดาวเทียม 77 จว. (GISTDA) และสภาพอากาศ (OpenWeather) สู่มาตรฐานระบบ
Memory Cache
In-Memory Cache Adapter (TTL 15m) ลดภาระ External API ตอบสนองไว < 30ms
1. Loose Coupling (ลดการพึ่งพากัน)
Domain Logic ไม่ผูกติดกับ SDK ภายนอกหรือระบบฐานข้อมูล สามารถเปลี่ยน Provider ได้ทันที
2. 100% Testability (ทดสอบได้สมบูรณ์)
สามารถสลับไปใช้ Mock Repository และ Mock Weather Data เพื่อรัน Automated Unit Test ได้
3. Dynamic Risk Scoring (ประเมินสด)
ปรับเปลี่ยนสูตรคำนวณความเสี่ยงตามฤดูกาลหรือสภาพอากาศแบบ Run-time โดยไม่ต้องแก้โค้ด Domain
4. High Performance (ประสิทธิภาพสูง)
ลดเวลาค้นหาข้อมูลเชิงพื้นที่ด้วย Spatial Indexing และ In-Memory Cache ความเร็วสูง

ระบบคำนวณเชิงพื้นที่ & REST API Engine

การคำนวณอาณาเขตน้ำท่วมอัตโนมัติ (Convex Hull) และการเชื่อมต่อข้อมูลความเร็วสูง

Clustering
รวมกลุ่มจุดรายงานที่อยู่ในรัศมี 500 ม. เกิน 2 รายการ หรือมีระดับน้ำวิกฤต
Convex Hull
คำนวณจุดยอดรูปหลายเหลี่ยม ส่งออก GeoJSON Polygon ขอบเขตพื้นที่น้ำท่วม
GISTDA 77
ประมวลผลข้อมูลภาพถ่ายดาวเทียมน้ำท่วมขังรายวัน แยกรายจังหวัดทั่วประเทศไทย
Fast API
สถาปัตยกรรมแคชข้อมูล ตอบสนองคำขอของ Front-End ได้อย่างรวดเร็วภายใน 15-30ms
GET /api/points
ดึงรายการจุดเฝ้าระวังน้ำท่วม พิกัด และระดับความเสี่ยงแบบ Real-time (<20ms)
POST /api/reports
รับรายงานเหตุน้ำท่วมด่วนจากประชาชน พร้อมพิกัด GPS ภาพถ่าย และเบอร์ติดต่อ (<80ms)
GET /api/zones
ดึงอาณาเขต Polygon พื้นที่น้ำท่วมที่คำนวณด้วย Convex Hull ในรูปแบบ GeoJSON (<35ms)
GET /api/gistda & /stats
ดึงชั้นข้อมูลดาวเทียม 77 จังหวัด และข้อมูลสถิติสรุปภาพรวม KPI สำหรับแดชบอร์ด (<30ms)

ปรัชญาการออกแบบ: White Modern UI Architecture

ตัดสิ่งรบกวนสายตา สร้างมิติด้วยระดับชั้นของสีพื้นผิว (Surface Layering)

No Border
ห้ามมีเส้นขอบกรอบตัดสายตา ใช้ความสะอาดของพื้นที่และระยะห่างสร้างขอบเขตตามธรรมชาติ
No Shadow
ห้ามมีเงาดำเบลอๆ ซ้อนกัน ตัดความเทอะทะให้เบาสบายตาและคมชัดระดับ Retina Display
Layering
สร้างมิติความลึกด้วย 4 ระดับสี Slate 100 ➔ Pure White ➔ Slate 50 ➔ Slate 200
Radius
สัดส่วนความมนสมดุล องค์ประกอบนอกมนกว่าใน (20px > 14px > 10px > 8px)
1. Thai-First & Human Centric
ใช้ภาษาไทยเข้าใจง่าย สุภาพ ไร้ศัพท์เทคนิคบนหน้าจอ (Controller, JSON) และไร้วงเล็บซ้ำซ้อน
2. High Information Density
จัดวางข้อมูลกระชับ อ่านง่าย มองเห็นภาพรวมของสถานการณ์ครบถ้วนในหน้าจอเดียว
3. Status Color Tokens
แดง (วิกฤต) • ส้ม (เสี่ยงสูง) • เหลือง (ปานกลาง) • ฟ้า (เฝ้าระวัง) • เขียว (ปกติ)
4. Typography Hierarchy
Noto Sans Thai สำหรับภาษาไทยคมชัด ผสาน Inter สำหรับตัวเลขและรหัสพิกัด

OpenStreetMap
เรนเดอร์แผนที่เวกเตอร์เต็มจอ 100vw, 100vh ซูมและแพนลื่นไหล 60 FPS ด้วย Leaflet 1.9.4
Risk Markers
หมุดแยก 4 สีตามระดับความเสี่ยง พร้อม Interactive Popup แสดงระดับน้ำและรูปถ่ายจริง
GISTDA Layer
สวิตช์เปิด-ปิดเลเยอร์ภาพถ่ายดาวเทียมน้ำท่วม 77 จังหวัดรายวันจาก GISTDA
Polygon Zones
แสดงอาณาเขตพื้นที่วิกฤตด้วยแรเงาสีแดงโปร่งแสงตามขอบเขต Convex Hull
1. Floating Top Navbar (แถบนำทางลอยตัว)
โปร่งแสงลอยตัวด้านบน สลับหน้า Map / Dashboard / API ได้อย่างรวดเร็ว
2. Auto-Geolocation (ตรวจจับพิกัดอัตโนมัติ)
ดึงตำแหน่ง GPS ของอุปกรณ์ทันทีเพื่อโฟกัสจุดเสี่ยงและรายงานที่ใกล้ตัวที่สุด
3. Incident Photo Viewer (ดูรูปสถานที่จริง)
คลิกที่หมุดเพื่อดูระดับความสูงน้ำ (เมตร) เวลาที่รายงาน และภาพถ่ายสถานที่จริง
4. Floating Report Button (ปุ่มแจ้งเหตุด่วน)
ปุ่มสีน้ำเงินมุมขวาล่างเด่นชัด เข้าถึงฟอร์มรายงานเหตุฉุกเฉินได้ในคลิกเดียว
